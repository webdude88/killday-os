Start here

This drive is a complete offline library and computer system. It needs no internet. Corrupted? Still alive.

If someone is badly hurt or in danger, contact emergency services or a qualified professional first, if there is any way to do so. Everything in this library is reference material and is not a substitute for professional care.

Find something fast

Go to Search and type a few plain words, like "treat burn" or "boil water". Results come from every guide on the drive.

Browse by subject

The tiles on the main page group the library by subject: medical, water, food, shelter, energy, communications and more. Faded tiles are not installed on this drive.

Use the map

Open the Map, pick a region from the list, then drag to move and scroll to zoom.

Save your own files

Choose Normal or Persistence on at the boot menu and enter your passphrase. Then anything in your home folder is kept, encrypted, between boots. If you forget the passphrase, those files cannot be recovered by anyone.

Rescue files from a dead PC

Open Rescue my PC's files here or from the desktop. It explains how to copy files off a computer that will not start without damaging them further.

Save power

Click Battery saver on the desktop to dim the screen and slow the machine down so a laptop lasts longer.

No way to boot this drive?

Plug it into a working Windows or Mac computer, open the KILLDAY_LIB drive, and run START-WINDOWS or START-MAC. The library opens in your normal browser.
