Rescue my PC's files

Follow these steps in order. The goal is to copy your files somewhere safe before trying any repair.

Do not run repair tools, format, or install anything on a failing disk until your files are copied off. Repairs write to the disk and can destroy what is left. Work on a copy whenever you can.

1. Get somewhere to put the files

Plug in a second USB drive or external disk with enough free space. Do not save rescued files to the disk you are rescuing.

2. Look at the disk first

Open the Thunar file manager. The PC's disks are listed on the left. Click one to mount it. Kill-Day OS never mounts your PC's disks by itself.

If the disk is encrypted with BitLocker or LUKS, you will need its password or recovery key. Without it, the files cannot be read.

3. If the files are visible, copy them

Copy the most important files first: documents, photos, then everything else. A dying disk may only last for a short time. If a copy stalls on one file, skip that file and move on.

4. Check the disk's health

Open Terminal Emulator and run sudo smartctl -H -A /dev/sda, using the right disk name from the lsblk command. A result of FAILED, or reallocated or pending sectors above zero, means the disk is dying. Stop using it once your files are off.

5. If the disk is failing or will not mount

Make a full image with ddrescue. It skips bad areas and comes back to them later. The image must go to a different, larger disk.

sudo ddrescue -d -r2 /dev/sda /media/survivor/BACKUP/disk.img /media/survivor/BACKUP/disk.map

Check the order carefully. The first path is the failing disk and the second is the destination. Reversing them erases your data permanently.

If the copy is interrupted, run the same command again. The map file lets it pick up where it stopped.

6. Recover deleted files or lost partitions

Run sudo testdisk disk.img on the image, or sudo photorec disk.img to pull out photos and documents by file type. Always save recovered files to a different disk.

7. When to stop

If the disk clicks, grinds or is not detected at all, turn the PC off. Every extra minute of running can cause more damage. If the data is worth paying for, a professional recovery lab is the next step.
