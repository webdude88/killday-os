About Kill-Day OS

Corrupted? Still alive. Kill-Day OS is a bootable offline survival library built only from open-source, freely licensed and public-domain material.

Software and fonts

Built on Debian GNU/Linux with live-build. Library engine: Kiwix (GPL-3.0). Search: Pagefind (MIT). Maps: MapLibre GL JS (BSD-3-Clause), PMTiles and Protomaps (BSD-3-Clause), map data from OpenStreetMap contributors (ODbL), and the optional home-area outline from the US Census Bureau (public domain). Fonts: Press Start 2P, JetBrains Mono and Space Grotesk (SIL Open Font License 1.1).
